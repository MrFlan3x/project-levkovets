# Практична робота 4

## 1. Картка проєкту

| Поле | Зміст |
|---|---|
| Назва | EduTask — система навчальних завдань |
| Проблема | Завдання губляться в чатах; складно стежити за термінами та перевіркою. |
| Цільові користувачі | Студент, викладач, адміністратор. |
| Ключова цінність | Завдання, дедлайни й оцінки в одному простому вебзастосунку. |
| Основні функції | Вхід за ролями; створення завдань; подання робіт; статуси й дедлайни; оцінювання. |
| Очікуваний результат | Проєктна документація та прототип інтерфейсу. |

## 2. Бачення продукту (Vision)

Для студентів і викладачів коледжу, яким потрібно впорядковувати навчальні завдання, EduTask — це вебзастосунок для створення, здавання та перевірки робіт. На відміну від складних навчальних платформ, він має простий інтерфейс для невеликих груп.
